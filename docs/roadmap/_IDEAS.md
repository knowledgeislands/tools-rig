# Ideas

Ideas this repository may take up later. None is a work record: an idea here has no identifier, horizon or status, and it returns to the roadmap only when Kris brings it back. Each bullet says in plain language what the idea is for and links to its full text in `docs/ideas/`, kept as it was when it left the roadmap under the roadmap sweep of 27 October 2026.

- **Rig manages app configuration** - Let Rig manage an application's configuration as well as its installation, dividing cleanly with chezmoi; folded into the application configuration touch points idea. [Full text](../ideas/KI-TOOL-RIG-CORE-064-unmanaged-configuration-scan.md) (was `KI-TOOL-RIG-CORE-064`).
- **Application configuration touch points** - Let a declared tool record where on the machine it keeps its configuration and state, so Rig can say what each application changes and what to review when it is removed; carries the configuration scan idea. [Full text](../ideas/KI-TOOL-RIG-CORE-072-application-configuration-touch-points.md) (was `KI-TOOL-RIG-CORE-072`).
- **Host-specific software retirement** - Keep a retired tool's identity in the catalogue so a later discovery on a host where it is not selected is reported as a removal candidate; needs host and profile identity settled first. [Full text](../ideas/KI-TOOL-RIG-CORE-074-host-specific-software-retirement.md) (was `KI-TOOL-RIG-CORE-074`).
